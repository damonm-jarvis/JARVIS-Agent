# JARVIS Agent — V64

GitHub Pages-ready JARVIS dashboard.

## Startup fix
V64 includes a final INITIATE failsafe that forces the startup button visible and clickable even if an earlier initialization routine fails.

## GitHub Pages
Upload the contents of this folder to the repository root. Make sure `index.html` is directly in the root.

The browser UI is static. Full agent actions that require a backend/API server must be deployed separately.
